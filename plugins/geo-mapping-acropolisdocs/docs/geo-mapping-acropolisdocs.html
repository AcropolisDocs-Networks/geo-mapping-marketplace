Scope — what it covers, and what it does not

What it covers
  • Vector geodata in ten formats, from a file, a public data service or the bundled reference library.
  • Print maps (PDF, PNG, SVG, georeferenced PDF and GeoTIFF) and single-file interactive web maps.
  • Mobile-network map types - site maps, sector wedges, coverage footprints, market rollups, program status - and the general ones.
  • North American boundaries, counties, markets and context layers in the library; any area from your own data.
  • Street and terrain backgrounds from licensed providers or your own tiles.
  • Rasters on the map - a GeoTIFF on the brand's ramp, relief and contours from USGS 3DEP or your own DEM, a WMS or ArcGIS picture under your data - and line of sight, viewsheds and population under a footprint from a grid.
What it does not cover
  • Imagery classification and RF propagation. Coverage here is what you supply, or wedges drawn for display; line of sight is bare earth, not a link budget.
  • Vector tiles and PMTiles files as a background (not in this release).
  • Heat maps (not in this release).
  • Writing data back to a service. Every service is read-only.
  • Google Maps and Bing Maps tiles, which their terms do not allow here.

The plugin never holds a password, key or token in a chat, a map or a package. Your keys live in a private folder on your own computer (the API keys tab), and a login-protected server is reached through a request kit you run yourself.

Common questions

How do I open this guide from a chat? Type /geo-mapping-acropolisdocs:map-guide, or ask "open the map guide". It opens this page in the session and helps you pick a task, then hands you to the skill that makes it.

How do I check the version? Run /plugin list. It should show geo-mapping-acropolisdocs at 1.13.0. An older number means a stale copy is still installed; see re-install.

Can I install two editions side by side? No, and there is no need. There is one geo-mapping plugin since 1.7.0, and other brands are packs you add (the Customization tab). If an older edition is still installed beside it, every map skill stops and says which two; remove the old one.

Why is my map in Web Mercator? Because it has a street or terrain background. Tiles exist only in Web Mercator, so a map with tiles is drawn in it. Without tiles the plugin picks a projection for the map's extent and says why in the map's notes.

Where does a tile provider's key go? In your own credential folder on your computer. /geo-mapping-acropolisdocs:map-credentials add carto-positron makes an empty private file; you paste the key into it in Notepad, and the plugin's server on your computer reads it when a map needs tiles and never prints it. Never paste a key into the chat. API keys.

Is my client data sent anywhere? Your files are read where you work and nowhere else. The plugin fetches only public data itself. Client-confidential sites can be generalized on a map meant for outside readers.

The map is in the wrong brand. Name the brand when you ask, or set your default with /geo-mapping-acropolisdocs:brand. This edition carries AcropolisDocs.

Before you start — what the machine needs

Maps are drawn by Python libraries (GeoPandas, Shapely, pyproj, WeasyPrint and a few more). They are not part of the plugin file, so a machine without them fails when it first draws a map, not at install. Install them once:

Install the map packagesrun once, at the plugin root
pip install -r requirements.txt
"Run the map doctor." It reports which outputs this machine can make (SVG, PDF, PNG, web pages, the geodata formats and services) and what each missing package costs you. Ask it to fix what is missing and it installs it. Run it first, and again whenever a map does not appear. Everyday asks →

The bundled data-service server runs on Windows itself. The first time it starts it sets up its own Python environment in your user profile and says when it is done; restart the plugin then. The maps themselves are drawn in the session's sandbox.

Where the files go

Maps are written to the folder you connected to the session, so they open from your file manager like anything else. Each map comes with its MapSpec (the recipe that rebuilds it) and a provenance file. The plugin keeps its own working files in a .geo-mapping folder you never need to open.

API keys

Some public data needs a free key: the Census Data API, NOAA climate data, a tile provider. Each person uses their own key. It lives in one private file on your computer, is sent only to the one host it belongs to, and never appears in a chat, a map, a log or a package.

Set a key up

You register a key once, in plain words or with the command, then paste the key into the file it names, in your own editor. Claude never asks for a key and does not use one typed into the chat.

  1. Get the key. Sign up at the provider (the table at the bottom of this tab has each address). Most keys for public data are free.
  2. Register it. Ask "add my Census key", or type the command below. It makes your private credential folder if needed, and an empty, private key file.
  3. Paste it in. Open the file it names in Notepad (or any editor), paste the key as the only line and save. Nothing else goes in the file.
  4. Check it. Run check: it answers yes or no for present, private, outside your project folders and filled in. With your yes it sends one small test request to the provider.
  5. Use it. Ask for the map. A map names the key as cred:census, never by value; the plugin's server on your computer adds it to the request and drops it.
The key commandstype in the chat, or ask in plain words
# register once (the file it names is empty and private)
/geo-mapping-acropolisdocs:map-credentials add census
# paste the key into that file in Notepad, save, then
/geo-mapping-acropolisdocs:map-credentials check census
# see every key you hold (names, hosts, dates; never a value)
/geo-mapping-acropolisdocs:map-credentials status
# replace a key, or take one out
/geo-mapping-acropolisdocs:map-credentials rotate census
/geo-mapping-acropolisdocs:map-credentials remove census

Where your keys are kept

WhereOne file per key in your credential folder: %USERPROFILE%\.geo-mapping\credentials\ on Windows, ~/.geo-mapping/credentials/ elsewhere. You can move the folder with credentials_dir in ~/.geo-mapping/config.yaml.
What the folder holdsThe key files and credentials.yaml, a registry of names, hosts, classes and dates. The registry never holds a key.
PrivateEach file is readable by you alone: mode 600 on macOS and Linux, an access list for your Windows account only. check reports and fixes it (fix=true), and on Windows prints the PowerShell line to look for yourself.
Never inside your workA key file is refused inside the plugin, a project folder, an output folder or a synced folder such as OneDrive, so it cannot travel with a map or a package.
Who reads itThe plugin's own server, running as you on your computer. It reads the key when a request needs it, sends it and forgets it. The folder is never connected to the chat.

How their use is restricted

What the plugin does with a key, every time, whichever skill or pipeline asks for it.

One host per keyA key is registered for one host (api.census.gov) and how it is sent: a query parameter, a header, a bearer token, Basic login, or a place in the address. It is never sent anywhere else, and only over https.
Two classessecret (every key unless you say otherwise) is never written into any output: a printed map's tiles get it at send time on your computer. browser is a tile key the provider makes for web pages; it may go into a page only after you have restricted it to your site's domain at the provider and said so (--class browser --confirm-restricted).
Masked everywhereWhat the server returns has the key masked; logs, records and provenance name the credential (cred:census), never its value.
Rejected, expired, oldA key the provider rejects is marked rejected and not sent again until you rotate it. A token with an end date is flagged two weeks before and refused after. A key is due for review after a year, and an old file left by a rotation is pointed out after a week.
Pasted into the chatTreated as exposed: it is not used, repeated or saved. Get a new key from the provider and rotate.
Checked before a releaseEvery package is scanned for key patterns before it is built, and audit looks for a registered key's exact value in any folder you name, without showing it.

Going beyond the defaults

The plugin's defaults need nothing from you: the bundled background and reference layers, the US Census geocoder, USGS elevation (and the AWS terrain tiles outside the US, with their credit printed), the FOSSGIS Valhalla router within its limits, transit times from your own GTFS feed, and the public services the reference library lists as active. Anything you add or choose beyond them is a customization: a key you register, OpenStreetMap's own tile servers, Nominatim geocoding, a free tier meant for non-commercial use, a data service you save. You accepted each provider's terms when you signed up or got your key, so the plugin does not ask you to accept them again, and nothing is hidden in a map's settings. It asks once, in one plain statement, that you keep each customization within the terms you accepted. A registered key counts as that yes for its own service.

Customization

The plugin ships in the AcropolisDocs brand, and this guide always wears it. Your maps do not have to: add your own brand, pick a style pack, and set your defaults. Nothing is rebuilt and the plugin itself is never changed, so an update keeps everything you set.

Your own brand

A brand is a small pack: a name, colours, a logo. Add one and every map can be drawn in it; make it your default and every new map is. The shipped brand stays available beside it.

  1. Have three things ready. The brand's name, its main colour as a hex code (and up to four more, most important first), and its logo (an SVG file is best; a PNG or JPEG works). A second file for dark backgrounds is optional.
  2. Make the pack. Ask "add my brand", or type the first command below. The plugin turns your colours into map colours and tells you each one it had to move, and why.
  3. Look at one map. Ask for any map "in the Acme Fiber brand". Check the logo, the colours and the legend.
  4. Make it the default. Type the set command. New maps use your brand; maps already made keep the brand they were made in.
The brand commandstype in the chat, or ask in plain words
# make a brand from a name, colours and a logo
/geo-mapping-acropolisdocs:brand new --name "Acme Fiber" --color "#1A5FB4" --color "#C64600" --logo acme.svg
# or add a pack folder (or brand .json) someone gave you
/geo-mapping-acropolisdocs:brand add ./brand-packs/acme-fiber
# make it your default, and see what is here
/geo-mapping-acropolisdocs:brand set acme-fiber
/geo-mapping-acropolisdocs:brand
# copy a pack to share it or keep it with a project; take one out
/geo-mapping-acropolisdocs:brand export acme-fiber --out ./brand-packs
/geo-mapping-acropolisdocs:brand remove acme-fiber

What a brand changes

ColoursYour colours become the map's accents. From them the plugin derives the class colours, the sequential and diverging ramps, land, water and the dark theme, once, and stores them in the pack.
LogoDrawn small at the bottom left of a print map and of a web map, as the shipped brand's is. One SVG for light backgrounds, optionally another for dark.
NamesYour brand's name is the Author and Company in each file's properties, and the start of each file name (acme-fiber_...).
Trademark lineOptional. If your brand requires one, it is printed in the map's footer.

What stays the same for every brand

TypefaceInter, for every brand. A style pack may bring its own faces; a brand does not.
LayoutTitle top left, legend top right, logo bottom left, locator bottom right, unless you ask otherwise.
The checksContrast, colour-blind safety, credits and licences are checked for your brand exactly as for the shipped one.
The hidden creditEach file's properties name the plugin that made it (AcropolisDocs). It is never drawn on a map.

Good to know

Colours that had to moveA colour too pale to read on the map's background is deepened; two colours a colour-blind reader could not tell apart are separated; a black background is lifted to very dark grey. Each change is listed when the pack is made.
Logos are plain drawingsAn SVG that carries a script, a link, an event handler or an embedded page is refused: a logo is drawn into web pages. Export it again as plain SVG with outlined text. A PNG or JPEG logo up to 180 KB is taken as it is.
Where a pack livesIn your project's .geo-mapping/brands/ folder, outside the plugin. Ask "keep this brand in my library" and it is saved on your own computer; in a new project ask "use my Acme Fiber brand" and it is brought in. Or keep an exported copy and add it again; GEO_MAPPING_BRANDS names a shared folder.
Your right to a brandA client's marks belong to the client. The plugin does not check that you may use a brand; that is yours to know.
